## Recommended learning order

**Run → inspect → replay → test failure → explain the design.**

Use the [walkthrough](WALKTHROUGH.md) first. It works with Python 3.11+ and needs no cloud account. Keep the [warehouse diagram](../docs/diagrams/warehouse-model.svg) beside your SQL queries and use the [interview questions](../docs/INTERVIEW_QUESTIONS.md) to check your understanding after each lesson.

The local route is verified. Cloud integration, final audio/video and a Power BI report still require execution or production work; see [implementation status](../docs/IMPLEMENTATION_STATUS.md).
