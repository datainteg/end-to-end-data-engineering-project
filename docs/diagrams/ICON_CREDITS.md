[Machine-readable source records](icons/sources.json) include URLs and SHA256 hashes for each vendored icon. Files in `icons/` retain downloaded artwork. The diagram generator resizes icons and prefixes SVG definition IDs in embedded copies to prevent repeated gradient IDs from colliding; it does not redraw the logos. Service names remain visible alongside the artwork.

Diagram structure, labels and generator code are original project content. If reusing diagrams, retain this credits file and the linked notices with your copy.
